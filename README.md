# LJT-Homepage

Junteng Liu's personal academic homepage, built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template and hosted on GitHub Pages.

## Structure

- `_config.yml` — site-wide configuration and sidebar profile (name, bio, email, GitHub, Google Scholar, X)
- `_data/navigation.yml` — header navigation
- `_pages/about.md` — home (About) page with academic background, research experience, publications, skills, and contact information
- `_pages/publications.html` — publications page
- `_publications/` — individual publication entries

## Local development

See the [Academic Pages documentation](https://github.com/academicpages/academicpages.github.io) for setup instructions.
